Class reference

All 118 classes of the library, grouped by area, with a short example for each. Every class keeps the interface of the original Turbo Vision 1.0; notes marked Port note describe where the Linux version behaves differently.

Using the library

A source file states which classes it needs with Uses_ macros and then includes tv.h, which pulls in exactly the required headers (and their dependencies):

#define Uses_TApplication
#define Uses_TWindow
#define Uses_TDialog
#define Uses_TButton
#define Uses_MsgBox
#include <tv.h>

Build with the library's include directories and link the whole archive, so that the self-registering streamable classes are kept by the linker:

g++ -std=c++11 -Itv/include -Itv/include/compat -c app.cpp
g++ -o app app.o -Wl,--whole-archive tv/lib/libtv.a -Wl,--no-whole-archive

Views are allocated with new and handed to their owner with insert(); the owner destroys them. Release objects you own with TObject::destroy().

Basic types

Geometry, commands, palettes, draw buffers and events used by every view.

TObject

header tvobjs.hUses_TObject

Root of the class hierarchy. Provides a virtual destructor, shutDown() and the static destroy() that every view and collection should be released with.

#define Uses_TObject
#define Uses_TWindow
#include <tv.h>

TWindow *w = new TWindow( TRect( 0, 0, 40, 10 ), "Temp", wnNoNumber );
// ... use it ...
TObject::destroy( w );      // calls shutDown() and then deletes the object

TPoint

header objects.hUses_TPoint

A pair of short coordinates (x, y) with arithmetic and comparison operators. It is an aggregate: there is no constructor.

TPoint p = { 10, 5 };
TPoint d = { 1, 1 };
p += d;                         // p == {11, 6}
if( p == view->size ) { /* ... */ }
TPoint local = view->makeLocal( event.mouse.where );

TRect

header objects.hUses_TRect

A rectangle given by its top-left corner a and the bottom-right corner b (exclusive). Used for view bounds and clipping.

TRect r( 0, 0, 40, 12 );        // 40 columns x 12 rows
r.move( 5, 2 );                 // shift by (5,2)
r.grow( -1, -1 );               // shrink by one cell on every side
if( r.contains( mouse ) ) { /* ... */ }
TRect inside = getExtent();     // (0,0)-(size.x,size.y) of a view

TCommandSet

header views.hUses_TCommandSet

A set of command codes 0..255. Used to enable and disable commands for the whole application (menus and buttons gray out automatically).

TCommandSet cs;
cs += cmSave;
cs += cmSaveAs;
TView::disableCommands( cs );       // gray out Save and Save As
// later:
TView::enableCommands( cs );
if( TView::commandEnabled( cmSave ) ) { /* ... */ }

TPalette

header views.hUses_TPalette

Maps a view's color indexes into its owner's palette. A view returns its palette from getPalette(); the indexes are then resolved up the owner chain until the application palette yields a text attribute.

#define cpMyView "\x06\x07"      // entries 6 and 7 of the owner palette

class TMyView : public TView
{
public:
    TMyView( const TRect& r ) : TView( r ) {}
    virtual TPalette& getPalette() const
    {
        static TPalette palette( cpMyView, sizeof( cpMyView ) - 1 );
        return palette;
    }
};

TDrawBuffer

header drawbuf.hUses_TDrawBuffer

A row of character/attribute cells that a view fills and then writes with writeLine() or writeBuf(). Up to maxViewWidth (1024 in this port) cells. Characters are bytes of the active code page.

void TMyView::draw()
{
    TDrawBuffer b;
    ushort color = getColor( 1 );
    b.moveChar( 0, ' ', color, size.x );        // clear the row
    b.moveStr( 1, "Hello", color );             // plain text
    b.moveCStr( 8, "~F~ile", getColor( 0x0201 ) ); // '~' toggles highlight
    b.putChar( 0, '\x10' );                     // a CP437 glyph
    writeLine( 0, 0, size.x, size.y, b );
}

TEvent

header system.hUses_TEvent

The event record (struct). what selects which union member is valid: mouse, keyDown or message. Related records: MouseEventType, KeyDownEvent, CharScanType, MessageEvent.

void TMyView::handleEvent( TEvent& event )
{
    TView::handleEvent( event );
    switch( event.what )
        {
        case evKeyDown:
            if( event.keyDown.keyCode == kbF5 )
                { refresh(); clearEvent( event ); }
            break;
        case evMouseDown:
            if( event.mouse.doubleClick )
                { open( makeLocal( event.mouse.where ) ); clearEvent( event ); }
            break;
        case evCommand:
            if( event.message.command == cmMyCommand )
                { doIt(); clearEvent( event ); }
            break;
        }
}

Views and groups

The visible building blocks. Every visible object is a TView; containers are TGroups.

TView

header views.hbase TObject, TStreamableUses_TView

Base of everything visible: a rectangle that can draw itself, handle events and be streamed. Derive from it and override draw() and handleEvent().

class THello : public TView
{
public:
    THello( const TRect& r ) : TView( r )
    {
        options |= ofSelectable;
        growMode = gfGrowHiX;
    }
    virtual void draw()
    {
        TDrawBuffer b;
        b.moveChar( 0, ' ', getColor( 1 ), size.x );
        b.moveStr( 1, "Hello, world", getColor( 1 ) );
        writeLine( 0, 0, size.x, size.y, b );
    }
};

TGroup

header views.hbase TViewUses_TGroup

A view that owns other views (subviews), draws them in Z-order, routes events to them and can run one of them modally with execView().

class TPanel : public TGroup
{
public:
    TPanel( const TRect& r ) : TGroup( r )
    {
        insert( new TStaticText( TRect( 1, 1, 20, 2 ), "Inside a group" ) );
        insert( new TButton( TRect( 1, 3, 11, 5 ), "~O~K", cmOK, bfDefault ) );
        selectNext( False );
    }
};

// iterate over the subviews
static void hideIt( TView *p, void * ) { p->hide(); }
group->forEach( hideIt, 0 );

TFrame

header views.hbase TViewUses_TFrame

The double/single line border of a window with the close and zoom icons and the title. A window creates it through its initFrame function, which you can replace.

class TMyWindow : public TWindow
{
public:
    TMyWindow( const TRect& r ) :
        TWindow( r, "Framed", wnNoNumber ),
        TWindowInit( &TMyWindow::initFrame ) {}
    static TFrame *initFrame( TRect r ) { return new TFrame( r ); }
};

TScrollBar

header views.hbase TViewUses_TScrollBar

A horizontal or vertical scroll bar. Broadcasts cmScrollBarChanged when its value changes.

TScrollBar *vs = window->standardScrollBar( sbVertical | sbHandleKeyboard );
vs->setParams( 0,       // value
               0, 99,   // min, max
               10,      // page step
               1 );     // arrow step
int pos = vs->value;

TScroller

header views.hbase TViewUses_TScroller

A view with a virtual area larger than itself, scrolled by two scroll bars. delta holds the scroll position, setLimit() the virtual size.

class TLinesView : public TScroller
{
public:
    TLinesView( const TRect& r, TScrollBar *h, TScrollBar *v ) :
        TScroller( r, h, v ) { setLimit( 200, 1000 ); }
    virtual void draw()
    {
        TDrawBuffer b;
        for( short y = 0; y < size.y; y++ )
            {
            char s[32];
            sprintf( s, "line %d", delta.y + y );
            b.moveChar( 0, ' ', getColor( 1 ), size.x );
            b.moveStr( 0, s, getColor( 1 ) );
            writeLine( 0, y, size.x, 1, b );
            }
    }
};

TListViewer

header views.hbase TViewUses_TListViewer

Abstract scrolling list with focus and selection. Override getText() and set the item count with setRange().

class TDaysList : public TListViewer
{
public:
    TDaysList( const TRect& r, TScrollBar *vs ) :
        TListViewer( r, 1, 0, vs ) { setRange( 7 ); }
    virtual void getText( char *dest, short item, short maxLen )
    {
        static const char *days[] =
            { "Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun" };
        strncpy( dest, days[item], maxLen );
        dest[maxLen] = EOS;
    }
};

TWindow

header views.hbase TGroup, TWindowInitUses_TWindow

A movable, resizable group with a frame, title and optional number (Alt-1..Alt-9). Windows created on the desktop grow with it (gfGrowAll | gfGrowRel) when the terminal is resized.

TWindow *w = new TWindow( TRect( 5, 2, 45, 14 ), "My window", 1 );
w->insert( new THello( TRect( 1, 1, 30, 2 ) ) );
TProgram::deskTop->insert( w );

TBackground

header app.hbase TViewUses_TBackground

The pattern that fills the desktop. The default pattern is the CP437 character 0xB0 (░).

class TMyDeskTop : public TDeskTop
{
public:
    TMyDeskTop( const TRect& r ) : TDeskTop( r ), TDeskInit( &initBackground ) {}
    static TBackground *initBackground( TRect r )
        { return new TBackground( r, '\xB2' ); }     // a denser pattern
};

TDeskTop

header app.hbase TGroup, TDeskInitUses_TDeskTop

The group between the menu bar and the status line that holds the windows. Can tile and cascade them.

TRect r = TProgram::deskTop->getExtent();
TProgram::deskTop->tile( r );       // cmTile
TProgram::deskTop->cascade( r );    // cmCascade
TProgram::deskTop->insert( new TWindow( TRect( 0, 0, 30, 8 ), "New", 0 ) );

TProgram

header app.hbase TGroup, TProgInitUses_TProgram

The application group: owns the desktop, menu bar and status line, runs the event loop. In this port its constructor switches the terminal to full screen mode, and getEvent() also handles terminal resizing and flushes the screen.

// static members give access to the main parts
TProgram::deskTop->insert( window );
TProgram::application->putEvent( event );

// idle() runs whenever there is no input
void TMyApp::idle()
{
    TProgram::idle();
    clock->update();
}

TApplication

header app.hbase TProgramUses_TApplication

TProgram plus the start-up and shutdown of the screen, event queue and history list. suspend()/resume() give the terminal back to the shell and take it again.

#define Uses_TApplication
#define Uses_TMenuBar
#define Uses_TSubMenu
#define Uses_TMenuItem
#define Uses_TStatusLine
#define Uses_TStatusDef
#define Uses_TStatusItem
#define Uses_TKeys
#include <tv.h>

class TMyApp : public TApplication
{
public:
    TMyApp() : TProgInit( &TMyApp::initStatusLine,
                          &TMyApp::initMenuBar,
                          &TMyApp::initDeskTop ) {}
    static TMenuBar *initMenuBar( TRect r )
    {
        r.b.y = r.a.y + 1;
        return new TMenuBar( r,
            *new TSubMenu( "~F~ile", kbAltF ) +
                *new TMenuItem( "E~x~it", cmQuit, kbAltX, hcNoContext, "Alt-X" ) );
    }
    static TStatusLine *initStatusLine( TRect r )
    {
        r.a.y = r.b.y - 1;
        return new TStatusLine( r,
            *new TStatusDef( 0, 0xFFFF ) +
                *new TStatusItem( "~Alt-X~ Exit", kbAltX, cmQuit ) );
    }
};

int main()
{
    TMyApp app;
    app.run();
    return 0;
}

Menus and status line

Menus are built from linked TMenuItem lists, usually with the + operators.

TMenuItem

header menus.hUses_TMenuItem

One menu entry: name with ~ hot letter, command, hot key, help context and the key text shown on the right. newLine() returns a separator.

// items are chained onto a TSubMenu with +
*new TSubMenu( "~F~ile", kbAltF ) +
    *new TMenuItem( "~O~pen...", cmOpen, kbF3, hcNoContext, "F3" ) +
     newLine() +
    *new TMenuItem( "E~x~it", cmQuit, kbAltX, hcNoContext, "Alt-X" )

// without a submenu, link the items through the last argument
TMenuItem *items =
    new TMenuItem( "~C~opy", cmCopy, kbNoKey, hcNoContext, 0,
    new TMenuItem( "~P~aste", cmPaste, kbNoKey ) );

TSubMenu

header menus.hbase TMenuItemUses_TSubMenu

A menu item that opens a submenu; the items added to it with + form that submenu.

TSubMenu& file =
    *new TSubMenu( "~F~ile", kbAltF ) +
        *new TMenuItem( "~N~ew", cmNew, kbNoKey ) +
        *new TMenuItem( "~O~pen...", cmOpen, kbF3, hcNoContext, "F3" );
TSubMenu& all = file + *new TSubMenu( "~H~elp", kbAltH ) +
        *new TMenuItem( "~A~bout", cmAbout, kbNoKey );

TMenu

header menus.hUses_TMenu

A list of menu items with a default item. Normally created for you by TMenuBar; build one yourself for a pop-up menu.

TMenu *menu = new TMenu(
    *new TMenuItem( "~C~opy", cmCopy, kbNoKey, hcNoContext, 0,
     new TMenuItem( "~P~aste", cmPaste, kbNoKey ) ) );

TMenuView

header menus.hbase TViewUses_TMenuView

Common base of the menu bar and menu boxes: keyboard and mouse navigation, hot keys. You rarely use it directly; execute() runs a menu and returns the chosen command.

// find the command bound to a hot key in the application menu
TMenuItem *item = TProgram::menuBar->hotKey( kbF3 );
if( item != 0 )
    message( TProgram::application, evCommand, item->command, 0 );

TMenuBar

header menus.hbase TMenuViewUses_TMenuBar

The one-line horizontal menu at the top. F10 (or a click) activates it, Alt+letter opens a submenu. With a Cyrillic keyboard layout Alt+letter still works by key position.

static TMenuBar *initMenuBar( TRect r )
{
    r.b.y = r.a.y + 1;
    return new TMenuBar( r,
        *new TSubMenu( "~F~ile", kbAltF ) +
            *new TMenuItem( "~O~pen", cmOpen, kbF3, hcNoContext, "F3" ) +
        *new TSubMenu( "~W~indow", kbAltW ) +
            *new TMenuItem( "~N~ext", cmNext, kbF6, hcNoContext, "F6" ) );
}

TMenuBox

header menus.hbase TMenuViewUses_TMenuBox

A framed vertical menu. The menu bar opens them for submenus; you can also run one as a pop-up.

TMenu *menu = new TMenu(
    *new TMenuItem( "~C~opy", cmCopy, kbNoKey, hcNoContext, 0,
     new TMenuItem( "~P~aste", cmPaste, kbNoKey ) ) );
TMenuBox *box = new TMenuBox( TRect( 10, 5, 24, 9 ), menu, 0 );
ushort cmd = TProgram::deskTop->execView( box );
TObject::destroy( box );
if( cmd != 0 )
    message( TProgram::application, evCommand, cmd, 0 );

TStatusItem

header menus.hUses_TStatusItem

A status line entry: text (may be 0 for an invisible hot key), key and command.

*new TStatusItem( "~F2~ Save", kbF2, cmSave ) +
*new TStatusItem( 0, kbF10, cmMenu )        // hot key only, not shown

TStatusDef

header menus.hUses_TStatusDef

A set of status items valid for a range of help contexts; the status line shows the first definition whose range contains the current context.

const ushort hcEditor = 100;                 // your help context

*new TStatusDef( hcEditor, hcEditor ) +      // while editing
    *new TStatusItem( "~F2~ Save", kbF2, cmSave ) +
*new TStatusDef( 0, 0xFFFF ) +               // everywhere else
    *new TStatusItem( "~Alt-X~ Exit", kbAltX, cmQuit )

TStatusLine

header menus.hbase TViewUses_TStatusLine

The bottom line with key hints. Override hint() to show help text for the current help context.

class TMyStatusLine : public TStatusLine
{
public:
    TMyStatusLine( const TRect& r, TStatusDef& d ) : TStatusLine( r, d ) {}
    virtual const char *hint( ushort ctx )      // hcEditor: your help context
        { return ctx == hcEditor ? "Type text; F2 saves" : ""; }
};

Dialogs and controls

Dialog boxes and the controls inside them. Controls exchange their values with a data record through getData()/setData().

TDialog

header dialogs.hbase TWindowUses_TDialog

A window for controls: gray palette, Esc cancels, Enter presses the default button. Usually run modally with execView().

TDialog *d = new TDialog( TRect( 0, 0, 40, 9 ), "Question" );
d->options |= ofCentered;
d->insert( new TStaticText( TRect( 2, 2, 38, 3 ), "Continue?" ) );
d->insert( new TButton( TRect( 6, 5, 18, 7 ), "~Y~es", cmYes, bfDefault ) );
d->insert( new TButton( TRect( 22, 5, 34, 7 ), "~N~o", cmNo, bfNormal ) );
d->selectNext( False );
ushort result = TProgram::deskTop->execView( d );
TObject::destroy( d );

TButton

header dialogs.hbase TViewUses_TButton

A push button that generates its command. bfDefault marks the button pressed by Enter; bfBroadcast broadcasts the command instead of sending it.

d->insert( new TButton( TRect( 10, 6, 20, 8 ), "~O~K", cmOK, bfDefault ) );
d->insert( new TButton( TRect( 22, 6, 32, 8 ), "Cancel", cmCancel, bfNormal ) );

TInputLine

header dialogs.hbase TViewUses_TInputLine

A one-line text editor. Its data is a char array of aMaxLen bytes (including the terminating 0). Typing UTF-8 characters stores the matching byte of the active code page.

struct { char name[31]; } rec = { "John" };

TInputLine *in = new TInputLine( TRect( 10, 2, 38, 3 ), 31 );
d->insert( in );
d->insert( new TLabel( TRect( 2, 2, 9, 3 ), "~N~ame", in ) );
d->setData( &rec );
if( TProgram::deskTop->execView( d ) == cmOK )
    d->getData( &rec );

TStaticText

header dialogs.hbase TViewUses_TStaticText

Fixed, word-wrapped text. A line starting with \x03 is centered.

d->insert( new TStaticText( TRect( 2, 2, 38, 5 ),
           "\x03Turbo Vision\n\n\x03" "for Linux" ) );

TParamText

header dialogs.hbase TStaticTextUses_TParamText

Static text with printf-style parameters taken from the data record. Port note: each parameter occupies one long-sized slot of the record (a long for %d %u %x %c, a pointer for %s).

struct { const char *name; long count; } rec = { "inbox", 42 };
TParamText *t = new TParamText( TRect( 2, 2, 38, 3 ),
                                "%s: %ld messages", 2 );
d->insert( t );
t->setData( &rec );         // shows "inbox: 42 messages"

TLabel

header dialogs.hbase TStaticTextUses_TLabel

A label linked to a control: clicking it or pressing its Alt+letter selects the control.

TInputLine *phone = new TInputLine( TRect( 12, 4, 32, 5 ), 20 );
d->insert( phone );
d->insert( new TLabel( TRect( 2, 4, 11, 5 ), "~P~hone", phone ) );

TCluster

header dialogs.hbase TViewUses_TCluster

Abstract base of check boxes and radio buttons: a column of items built from a TSItem list. Its data is a ushort.

// TCluster itself is abstract; use TCheckBoxes or TRadioButtons.
TCluster *c = new TRadioButtons( r, new TSItem( "A", new TSItem( "B", 0 ) ) );
ushort value = c->value;

TCheckBoxes

header dialogs.hbase TClusterUses_TCheckBoxes

Independent on/off items; the data is a bit mask (bit 0 = first item).

TCheckBoxes *cb = new TCheckBoxes( TRect( 2, 3, 20, 5 ),
    new TSItem( "~B~usiness",
    new TSItem( "~P~ersonal", 0 ) ) );
d->insert( cb );
ushort mask = 0x0003;           // both checked
cb->setData( &mask );

TRadioButtons

header dialogs.hbase TClusterUses_TRadioButtons

Mutually exclusive items; the data is the index of the selected item.

TRadioButtons *rb = new TRadioButtons( TRect( 22, 3, 38, 5 ),
    new TSItem( "~M~ale",
    new TSItem( "~F~emale", 0 ) ) );
d->insert( rb );
ushort choice = 1;              // "Female"
rb->setData( &choice );

TSItem

header dialogs.hUses_TSItem

A node of the string list given to clusters; the text is copied.

TSItem *items = new TSItem( "Red", new TSItem( "Green", new TSItem( "Blue", 0 ) ) );

Object streams

Persistent storage of objects and their links. Every streamable class registers itself; pointers to the same object are written once. The format on disk is the DOS one: int is 16 bits, long 32 bits, little-endian.

TStreamable

header tobjstrm.hUses_TStreamable

Interface of streamable objects: streamableName(), read(), write().

class TNote : public TObject, public TStreamable
{
public:
    TNote( const char *t ) : text( newStr( t ) ) {}
    static const char * const name;
    static TStreamable *build() { return new TNote( streamableInit ); }
protected:
    TNote( StreamableInit ) : text( 0 ) {}
    virtual void write( opstream& os ) { os.writeString( text ); }
    virtual void *read( ipstream& is ) { text = is.readString(); return this; }
private:
    virtual const char *streamableName() const { return name; }
    char *text;
};
const char * const TNote::name = "TNote";
