Turbo Vision for Linux

Borland Turbo Vision 1.0 for C++, ported from Borland C++ 3.1 / DOS to GCC and C++11. Programs run full-screen in any xterm-compatible terminal, including over ssh, and follow the size of the terminal window. The same sources also build on Windows with Visual Studio.

Class reference

The class hierarchy and all 118 classes by area — views, menus, dialogs, editors, help, collections, streams, resources, system layer — each with an example.

Porting guide

What differs from the original library, terminal behaviour and settings, and step-by-step instructions for moving DOS code to the port.

Add-ons

New classes in their own library: TAdvancedEditor (Ctrl+C/X/V/A, Ctrl+B selection, mouse wheel), line numbers with marks, TColoredEditor for syntax colouring, TYamlEditor, and the editor dialogs (Find, Replace, Save as).

Quick start

Linux, with g++ and GNU make:

cd linux
make                    # lib/libtv.a, lib/libtvaddons.a and the demos in bin/
cd bin && ./tvdemo      # Alt-X quits
./yamledit ../addons/demos/sample.yaml   # the YAML editor of the add-ons

Windows 10 or later, with Visual Studio 2022 or later (see Building on Windows):

cd linux
cmake -B build
cmake --build build --config Release    # lib/tv.lib, lib/tvaddons.lib, bin/*.exe
bin/tvdemo.exe

What is included

PathContents
include/Library headers (tv.h and the class headers); include/compat/ holds stand-ins for Borland headers such as dos.h, dir.h, iostream.h.
source/Library sources; source/platform/ is the new terminal driver: the shared part (screen output, key codes, code pages), posix/ for Linux and win32/ for the Windows console.
demos/TVDEMO, TVEDIT, TVFORMS (with the form generators), HELLO.
addons/New classes built on the library, in lib/libtvaddons.a with the header tvaddons.h: TAdvancedEditor, TBlockIndicator, TLineNumbers, TColoredEditor, TYamlEditor, TYamlEditWindow, editorDialogs(); the yamledit demo and tests (make check-addons).
docdemos/The examples from the Turbo Vision guide (TVGUID01–19, TVG17B).
help/TVHC, the help compiler, and the demo help source.
tools/keytest, tmux test scripts, the converter used for the port, this documentation's generator.
Makefile, CMakeLists.txtThe build: make on Linux, CMake with Visual Studio on Windows.
