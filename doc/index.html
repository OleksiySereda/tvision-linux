Turbo Vision for Linux

Borland Turbo Vision 1.0 for C++, ported from Borland C++ 3.1 / DOS to GCC and C++11. Programs run full-screen in any xterm-compatible terminal, including over ssh, and follow the size of the terminal window.

Class reference

The class hierarchy and all 117 classes by area — views, menus, dialogs, editors, help, collections, streams, resources, system layer — each with an example.

Porting guide

What differs from the original library, terminal behaviour and settings, and step-by-step instructions for moving DOS code to the port.

Add-ons

New classes in their own library: TAdvancedEditor (Ctrl+C/X/V/A, Ctrl+B selection, mouse wheel), line numbers, and TYamlEditor with YAML syntax colouring.

Quick start

cd linux
make                    # lib/libtv.a, lib/libtvaddons.a and the demos in bin/
cd bin && ./tvdemo      # Alt-X quits
./yamledit ../addons/demos/sample.yaml   # the YAML editor of the add-ons

What is included

PathContents
include/Library headers (tv.h and the class headers); include/compat/ holds stand-ins for Borland headers such as dos.h, dir.h, iostream.h.
source/Library sources; source/platform/ is the new terminal driver.
demos/TVDEMO, TVEDIT, TVFORMS (with the form generators), HELLO.
addons/New classes built on the library, in lib/libtvaddons.a with the header tvaddons.h: TAdvancedEditor, TBlockIndicator, TLineNumbers, TYamlEditor, TYamlEditWindow; the yamledit demo and tests (make check-addons).
docdemos/The examples from the Turbo Vision guide (TVGUID01–19, TVG17B).
help/TVHC, the help compiler, and the demo help source.
tools/keytest, tmux test scripts, the converter used for the port, this documentation's generator.
